# AGENTS.md

## Code style
- Lenguaje React Js
- Conserva el estilo de escritura y arquitectura del proyecto.
- Hojas de CSS para cada componente.
- eliminar Tailwind de los elementos y suplantar por CSS.
- Nombres claros.
- Evitar funciones, guardado de datos o cualquier caso/situación donde existan duplicados o duplicaciones.
- No usar `any`.
- No usar `!important`.
- No usar comando `npm run build`.
- Código lo más limpio posible.
- No modificar código legacy sin autorización.
- No modificar carpeta backend.
